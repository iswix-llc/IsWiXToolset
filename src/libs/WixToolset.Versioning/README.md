# IsWiX.Versioning - WiX Toolset Versioning library

The `IsWiX.Versioning` package provides methods for handling the various version types supported in the WiX Toolset. Standard 4-part versions (#.#.#.#) are supported as is SemVer (#.#.#-pre.#) and tolerance for very unusual versions created by other installation technologies.
